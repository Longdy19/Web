# Longdinovat Website

This is the Longdinovat website project built with **HTML + Tailwind CSS + AOS animations**.

---

## 🚀 Deployment Guide

### Option 1: GitHub Pages

1. Create a GitHub repository (e.g., `longdinovat-site`).
2. Upload all project files (including `index.html`, `style.css` if any, etc.).
3. Go to **Settings** > **Pages**.
4. Under "Branch", select `main` and `/root` folder, then click **Save**.
5. Your site will be available at:  
   `https://<your-username>.github.io/longdinovat-site`

📸 *Screenshot Example:*  
![GitHub Pages Setup](screenshots/github-pages.png)

---

### Option 2: Netlify (Easiest)

1. Go to [Netlify](https://www.netlify.com/).
2. Sign up (GitHub or email).
3. Click **Add New Site** → **Deploy manually**.
4. Drag & Drop the **entire project folder** here.  
5. Netlify will generate a live link instantly.

📸 *Screenshot Example:*  
![Netlify Upload](screenshots/netlify-upload.png)

---

### Option 3: Vercel

1. Go to [Vercel](https://vercel.com/).
2. Sign in with GitHub.
3. Import your repository containing this project.
4. Click **Deploy**.
5. Your site will be live at `https://<your-project>.vercel.app/`

📸 *Screenshot Example:*  
![Vercel Deploy](screenshots/vercel-deploy.png)
